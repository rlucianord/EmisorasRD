# Contribuir a Emisoras RD

## Flujo

1. Crear una rama:
   `feature/nombre`
2. Realizar cambios pequeños y verificables.
3. Ejecutar `gradle lint`.
4. Ejecutar `gradle assembleDebug`.
5. Actualizar documentación cuando cambie comportamiento.
6. Crear Pull Request.

## Convenciones

- Kotlin oficial.
- Nombres descriptivos.
- No incluir claves API.
- No almacenar URLs privadas.
- No copiar logos o contenido sin revisar derechos de uso.
- Mantener fuentes externas identificadas.

## Commits

Se recomienda Conventional Commits:

- `feat:`
- `fix:`
- `docs:`
- `refactor:`
- `test:`
- `chore:`
