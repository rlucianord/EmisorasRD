# Especificación funcional — Emisoras RD

## Propósito

Ser una puerta de entrada sencilla para escuchar emisoras de República Dominicana y consultar noticias asociadas, sin obligar al usuario a conocer las URLs de streaming.

## Navegación

### Emisoras

- buscador
- categorías
- lista
- favorito
- reproducir

### Favoritos

- emisoras marcadas por el usuario
- reproducción directa

### Noticias

- titulares RSS
- fuente
- fecha
- apertura en navegador

## Criterios de UX

- máximo tres acciones para comenzar a escuchar;
- texto legible;
- controles grandes;
- estados de carga visibles;
- errores explicados en lenguaje normal;
- no pedir permisos que no sean necesarios.

## Criterios técnicos

- tolerar fuentes externas caídas;
- no bloquear UI durante red;
- no guardar credenciales;
- reproducir audio en segundo plano;
- mantener documentación sincronizada.
