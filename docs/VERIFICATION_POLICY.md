# Política de verificación de emisoras

Emisoras RD debe distinguir entre **descubrir** una emisora y **afirmar que un dato es correcto**.

## No se publican como hechos verificados

- frecuencias inferidas por el nombre;
- streams copiados de sitios de terceros sin comprobación;
- logos sin fuente identificable;
- provincias deducidas solamente por una IP;
- marcas antiguas cuando existe evidencia de cambio.

## Evidencia mínima

Para una ficha marcada como verificada se recomienda disponer de:

- una fuente regulatoria o sitio oficial para identidad/frecuencia;
- una URL de stream que responda correctamente;
- fecha de última comprobación;
- fuente registrada en el catálogo.
