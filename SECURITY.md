# Seguridad

## Datos

La versión inicial no solicita cuentas ni contraseñas y no requiere credenciales de terceros.

## Secretos

Nunca incluir:

- keystores;
- passwords;
- tokens;
- API keys;
- credenciales de servidores.

## Reporte

Para problemas de seguridad, no publicar detalles explotables en un issue público. Utilizar un canal privado del mantenedor.
